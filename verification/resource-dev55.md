# 快照资源优化验证

本轮仅调整快照控制器、MBC5 桥和对应 mailbox 回归。

- MBC5 桥共享加载回传与物理 RAM 数据字寄存器，保留完整 64 位数据。
- 快照控制器新增 `DIAGNOSTICS` 参数，默认 `0`；关闭时不生成诊断存储，`op4` 仍返回 `fff2` 和 64 位零。
- 原严格诊断测试明确使用 `DIAGNOSTICS=1`；另补默认关闭的超时与非零标志回包测试。

## 已验证范围

隔离候选的完整 `run_snapshot.py` 回归通过，包括 ROM-only / 8 KiB / 32 KiB mailbox、真实状态引擎与请求管理器、全部内部 RAM、四银行物理卡 RAM 与 mapper 恢复、capture abort、调色板、HDMA、待机以及双速真实 CPU 恢复。新增默认关闭测试也通过。两份综合后的快照接线检查均通过。

使用相同新 T80 源码，基线与组合优化均综合成功：

| 资源 | 基线 | 优化后 | 差值 |
|---|---:|---:|---:|
| LUT | 19726 | 19566 | -160 |
| FF | 11111 | 10970 | -141 |
| ALU | 1730 | 1728 | -2 |
| BSRAM（综合报告） | 52 | 52 | 0 |

控制器自身减少 182 LUT、77 FF；MBC5 桥减少 64 FF。跨模块优化后全设计净减少 160 LUT。候选网表已无 `frozen_debug`、`debug_seen`、`req_seen` 存储。

本轮未运行布局布线，以上数据不证明时序、布线或真机快照验收已通过。
