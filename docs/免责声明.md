## 安装前的决定

安装者应先阅读安装说明，核对硬件配置、固件版本和文件校验值，再自行决定是否使用。请保留可用的官方更新途径，备份重要游戏进度及 microSD 上的整个 `SNAP` 文件夹。发行包所用 MCU 与 FPGA 应配套刷入。

刷写和测试可能出现开机异常、画面或音频问题、卡带不兼容、存读档失败、进度丢失、存档损坏，以及需要进一步工具恢复的情况。测试记录只说明被列出的设备、卡带和流程已经观察到的结果，无法覆盖全部硬件批次、耳机、内存卡、游戏和使用环境。

## 存档与供电

即时存档会记录游戏运行状态，读档会回退游戏现场及卡带 RAM 中的原生进度。读档最后阶段会向实体卡带 RAM 写入数据，此时断电或拔卡可能留下部分写入的原生存档。应等到界面显示完成后再关机或换卡。

每槽两代文件可帮助回退中断写入，FAT32 文件系统、存储卡控制器和物理断电仍可能影响数据完整性。临时待机需要持续供电，关机或断电会丢失待机现场。

## 当前验证范围

4.6-dev6.2-test 已在一台具备 ESP32、microSD 卡座和 GW5A-25 的掌机上验证原配《俄罗斯方块》保存、读档及新 3 号槽完整断电后恢复。其他卡带的范围和状态以项目记录为准。

当前 FPGA 最差建立时序余量为 +0.002 ns，长期稳定性仍待测试。后续离线优化候选的验证状态独立记录，公开 dev6.2 包对应已上机的构建。
