# ModRetro Chromatic v4.6-d7S1 开发测试版

**这是非官方、个人分享的开源固件。** 目标是带 ESP32、microSD 和 GW5A-25 的 Chromatic EVT1 X2。刷机前备份游戏普通存档和 microSD 上的 `SNAP`、`SNAPV`。刷机、断电和存档恢复失败可能导致开机异常或进度丢失。请先用能重新开始的游戏进度测试。

## 下载与安装

下载 `Chromatic-4.6-d7S1-install.zip` 并完整解压。macOS 双击 `一键刷机-Mac.command`，Windows x64 双击 `一键刷机-Windows.cmd`。入口会检查依赖、设备、配套镜像哈希和分区布局，并在写入前要求确认。请使用同包的 FPGA 与 ESP32 镜像。Windows 安装流程尚待真机验证。

配套源码是 `Chromatic-4.6-d7S1-source.tar.gz`。发行页中的 `SHA256SUMS` 用于校验两个下载包。解压后的安装包另有一份文件清单，供安装器校验。

## 功能与测试范围

- FAT32 卡根目录的 `ROMS` 支持 GB/GBC 文件和中英混合文件名。开机短按 MENU，切到「SD 游戏」，上下选择，A 打开。可从电脑用配套 USB 导入工具复制 ROM，串口速度适合少量文件。
- SD 即时存档第一阶段适用于 32 KiB、无映射器和无外置 RAM 的 ROM。进入「主页 → 即时存档」，START 选槽，A 保存，B、再 B 读取。三槽按 ROM 内容区分，每槽保留两代。SD 快照在 `SNAPV`，实体卡旧快照仍在 `SNAP`。
- 保留简体中文菜单和黑屏待机。长按 MENU 黑屏并松手，保持电源开关 ON，再短按 MENU 唤醒。本版关闭蓝牙及 USB 视频和音频采集。
- 一台真机已完成配套刷写、SD 游戏启动和单次 GB 测试保存。该次保存用时约 0.83 秒。另有机主录像演示 SD《坦克大战》关机重开、重新启动该游戏并读档回到同一关卡。三槽跨断电、GBC 真机快照、实体卡回归和跨机器稳定性仍待验证。保存速度仅记录这一次测试。
- 重开 USB 串口后曾出现活动 ROM 身份丢失，固件会拒绝该次快照。遇到此情况可先重新从「SD 游戏」启动 ROM。若硬件在应用快照期间失败，本版会冷启动游戏以恢复运行。
- 试验范围以外的 SD 游戏可使用游戏自身支持的普通存档。RTC、带 RAM 或特殊映射器的 SD 即时存档仍在开发。

## 回退

保留原版的配套固件和存档备份。需要退回前一测试版，可使用 `v4.6-dev6.2-test` 的完整刷机包。需要恢复官方版本时，使用 ModRetro 官方更新器或按官方支持流程处理，并核对 MCU 与 FPGA 均已恢复。相同 FPGA 版本号可能让更新器跳过写入。本版尚未真机验证完整恢复官方固件。
