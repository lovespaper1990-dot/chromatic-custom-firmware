## 下载

请下载完整的 [Chromatic-4.6-dev6.2-test-install.zip](https://github.com/lovespaper1990-dot/chromatic-custom-firmware/releases/download/v4.6-dev6.2-test/Chromatic-4.6-dev6.2-test-install.zip)，完整解压后运行。

自动生成的 GitHub 源码 ZIP 用于阅读和构建；刷写需要上面的完整发行包。[安装与使用](安装与使用.md) · [给 AI 的安装说明](给AI的安装说明.md)

## 本版功能

- 简体中文菜单、蓝牙耳机连接及记忆重连、机身滚轮控制蓝牙音量。
- 每款受支持的游戏三个即时存档槽，插卡开机自动识别游戏。菜单中 START 选槽、A 保存、B 再 B 确认读档。每槽保留两代文件。
- 改用块传输提高存读档速度，并修正 ROM 初始分页造成的重启后识别码变化。
- 电源保持 ON，游戏中长按 MENU 约 1.5 秒进入黑屏待机，短按 MENU 唤醒并继续。待机仍耗电，断电会丢失现场。
- 提供配套镜像、校验清单、定制源码、Mac/Windows 安装入口及 AI 安装指南。安装器校验镜像、检查唯一设备和兼容分区布局，随后写入并校验 FPGA 与 ESP32 应用。

## 已验证与待验证

原配《俄罗斯方块》已在 dev6.2 实机验证：保存约 0.99～1.12 秒，读取约 1.45～1.46 秒，2、3 号槽各自恢复不同位置，新 3 号槽完整断电后仍能恢复。旧识别码下的存档通过显式复制导入，机主确认旧 2 号槽位置恢复。

蓝牙音频及滚轮调节已在 dev4 由机主确认；dev6.2 同时使用蓝牙和高速存读档的压力测试待完成。《塞尔达》新版 GBC 单卡在 dev5.5 有可用反馈，dev6.2 待复测。《马里奥大陆》对应的标准 MBC1 无 RAM 快照模型已通过离线验证，实体卡保存待测。《星之海洋》新版单卡仍待逐盘复测。

目前开放 32 KiB ROM-only 及指定标准 MBC1、MBC5 配置。MBC2、MBC3/RTC、MBC1M、2 KiB RAM、特殊分页卡带及联机现场恢复尚未开放。详细范围见[测试说明](4.6-dev6-test测试说明.md)。不能据此保证所有 GB/GBC 卡带兼容。

当前 FPGA 时序检查通过，最差建立余量 +0.002 ns，余量较窄；长期运行、温度变化和其他硬件批次仍需验证。本次镜像与已上机的 dev6.2 一致，后续离线时序优化候选另行验证。

读档最后阶段会写回实体卡带 RAM，此时断电或拔卡可能损坏原生存档。早期开发版的旧识别码存档可能需要核对同一实体卡后显式导入。请先备份，再用可重新开始的进度测试。[实机记录](4.6-dev6.2-test测试说明.md)

## 卡死与恢复官方固件

普通游戏卡死可先 OFF、拔 USB、等待约 10 秒再开机。返回官方系统使用官方 ModRetro Updater，并确认 MCU 与 FPGA 两部分都实际完成官方写入。本版 FPGA 基础版本仍显示 18.14，更新器可能按相同版本跳过 FPGA；显示「已经最新」无法证明已经完整恢复。

**本项目尚未实测通过官方更新器从本版完整刷回官方固件。** 无法识别设备、更新中断或仅更新一部分时，应按官方支持提供的恢复步骤处理。[官方更新器说明](https://support.modretro.com/en_us/chromatic-firmware-updater-ryhoYnzCx)
