# ModRetro Chromatic 开发版安装与使用

本说明对应 4.6-dev5.5，适用于带 ESP32 和机内 microSD 卡槽的 Chromatic。它是非官方开发测试版。原配《俄罗斯方块》的 microSD 保存、读档和断电恢复已经通过真机验证；其他卡带的最新验收状态见 [dev5.5 测试记录](4.6-dev5.5测试说明.md)。

## 刷写

使用同一固件包内配套的 MCU 和 FPGA，先核对包根目录的 `SHA256SUMS`：macOS 执行 `shasum -a 256 -c SHA256SUMS`，Linux 执行 `sha256sum -c SHA256SUMS`。保留原固件及重要游戏进度的备份。

1. 掌机开机，用 USB 数据线连接电脑。用支持 GWU2X 的 openFPGALoader 执行 `openFPGALoader --detect --cable gwu2x`，核对目标为 GW5A-25。
2. 在固件包根目录写入 FPGA：`openFPGALoader --cable gwu2x --write-flash --verify --reset fpga/evt1_x2.fs`。等写入和校验都完成。
3. 使用 ESP-IDF 5.3 对应的 esptool 4.x，进入包内 `esp32` 目录，将 `PORT` 换成实际掌机串口，执行 `python -m esptool --chip esp32 --port PORT --after hard_reset write_flash @flash_args`。包内配置只列出引导程序、分区表和应用，没有 NVS 或整片擦除操作。
4. 重新启动，在菜单核对系统版本 `4.6-dev5.5`、MCU `0.13.8-dev5.5`。FPGA 的基础版本仍显示 `18.14`，定制位流以包内校验值和测试记录确认。

## 中文、蓝牙与临时待机

- 简体中文：在 `System → Language` 按 A 切换。
- 蓝牙：耳机进入配对模式，在主页“蓝牙”按 A 扫描、B 选择、A 连接。dev4 的蓝牙声音与机身滚轮调音量已由机主验证；本版沿用该实现。
- 临时待机：开关保持 ON，在游戏画面单独长按 MENU 约 1.5 秒，背光熄灭后松手；短按并松开 MENU 继续。短按 MENU 进入普通系统菜单。

待机在有供电的 FPGA、卡带与内存中保留现场，仍会耗电。关机、断电或拔卡会丢失这次待机现场；它与 microSD 快照不同。实际待机功耗和续航尚未测量。

## 主动保存与读档

插入有空余空间的 FAT32 microSD，在游戏中进入“主页 → 即时存档”。

- 按 A 主动保存，等待显示“已存档”和完成进度后再离开或关机。
- 按 B，再按 B 确认主动读档。完成后退出菜单，检查游戏是否回到保存位置。
- 当前自动读取这张卡的最新有效快照，没有多存档槽选择菜单。文件位于卡内 `SNAP` 目录；两代文件轮换用于保护中断写入。

本版开放 32 KiB ROM-only，以及 MBC5 类型 19/1A/1B、最高 8 MiB ROM、无 RAM 或 8/32 KiB RAM 的指定几何。实际是否适用仍由卡头和实体卡测试决定；其他类型显示“不支持”时不应阻止正常玩游戏。用户的《马里奥大陆》能运行，但当前即时存档未开放其类型。此前报告黑屏的 GBC 单卡中，《塞尔达》在 dev5.5 下已有可用反馈，《星之海洋》尚未复测，最新结果见测试记录。

读档会回退卡带 RAM 中的游戏自带进度；此版本仍需用可重开的进度测试。完整保存成功、文件校验通过和实际恢复成功是不同验收项，尚未通过的项目不作为正式支持承诺。联机现场恢复不在当前验证范围。
