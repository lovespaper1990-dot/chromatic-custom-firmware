# ModRetro Chromatic 4.6-dev2 定制固件

适用于配备 ESP32 和机内 microSD 卡座的 Chromatic。菜单支持简体中文和英文，并可连接蓝牙耳机。已完成仿真、FPGA 布局布线和静态时序验证。本版本尚未刷入实机。唤醒手感、实际功耗、耳机配对和断电读档仍待实机验证。

## 游戏中待机与唤醒

保持电源开关在 ON，在游戏画面单独按住 MENU 约 1.5 秒，等背光熄灭后松手。想继续时，短按一次 MENU 再松手。普通短按 MENU 仍可进入系统菜单，按键说明也可在“控制”页查看。

待机在仍有供电的 FPGA、卡带和内存中保留游戏现场，不用 microSD。待机仍会耗电。拨到 OFF、电池耗尽或拔出卡带会丢失这次待机现场。本机熄屏后，电脑上的 USB 采集软件可能保留上一帧画面，蓝牙耳机可能播完已收到的一小段声音。实际待机续航尚未测量。

原配《俄罗斯方块》、《塞尔达传说 大地之章》和 GB/GBC 版《星之海洋 蔚蓝星球》均可按此方式做真机测试。三盘尚未实机验证。《俄罗斯方块》可在方块下落时待机，30 秒后检查方块所在行和朝向；《大地之章》可比较林克和附近活动物体的位置；《蔚蓝星球》可检查道具菜单里的光标有没有移动或误确认。

## 文件与安装

先备份原固件和已有存档。FPGA 和 ESP32 使用本包中的配套版本。解压后，在包根目录可用 macOS 的 `shasum -a 256 -c SHA256SUMS` 或 Linux 的 `sha256sum -c SHA256SUMS` 核对每个文件。静态时序分析结果见 `verification/timing.txt`。完整时序报告为 `verification/evt1_x2.tr`，报告头的三个构建路径已简化为文件名。

1. 掌机开机，通过 USB 接入电脑。使用支持 GWU2X 的 openFPGALoader，从包根目录运行 `openFPGALoader --detect --cable gwu2x`，核对识别到 GW5A-25。写入 FPGA 的命令是 `openFPGALoader --write-flash --cable gwu2x --reset fpga/evt1_x2.fs`。`fpga/evt1_x2.bin` 是同一位流的二进制格式，两者任选一种与烧录器匹配的格式即可。
2. ESP32 使用 ESP-IDF 5.3 对应的 esptool 4.x。进入解压后的 `esp32` 目录，把 `PORT` 换成掌机的实际串口（macOS 通常形如 `/dev/cu.usbmodem…`），执行 `python -m esptool --chip esp32 --port PORT write_flash @flash_args`。命令会按 `flasher_args.json` 指定的地址写入引导程序、分区表和应用。保持供电直至工具报告写入完成。
3. 重新启动，在系统菜单核对版本 `4.6-dev2`。`System → Language` 可切换语言。在主页打开“蓝牙”，令耳机进入配对模式后按 A 扫描，B 切换设备，A 连接。

## 即时存档实机测试

将一张有空余空间的 FAT32 microSD 卡插入掌机。卡内可保留原有文件，固件会创建存档目录。将 `diagnostics/snapshot-test.gb` 写入与该 ROM 兼容的空白开发卡，插入掌机。测试 ROM 通过 A 增加计数、B 切换图形。让画面显示“03、菱形”，打开系统菜单的“即时存档”，按 A 保存。等屏幕显示完成后，回到游戏改变计数与图形，关机重新启动。在同一测试卡上打开“即时存档”，按 B 读档，再按 B 确认。预期画面回到“03、菱形”。

本版即时存档支持 32 KiB ROM-only、无卡带 RAM 的实体卡带，快照位于 microSD 根目录的 `SNAP` 文件夹。上述三盘请使用按键待机；本版 microSD 即时存档仍限上述 32 KiB 卡带。

FPGA 和 MCU 仓库使用相同的 GPL 第 3 版许可，副本见 `licenses/GPL-3.0.txt`。菜单字体的授权及署名见 `licenses/OSD-CJK-LICENSE.txt`。

设备与厂商工具说明可参考 [ModRetro FPGA 工程](https://github.com/ModRetro/oss-chromatic-console-fpga/tree/v18.14)和 [ModRetro MCU 工程](https://github.com/ModRetro/oss-chromatic-console-mcu/tree/v4.6)。
