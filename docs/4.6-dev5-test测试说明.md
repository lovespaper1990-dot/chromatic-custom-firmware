# ModRetro Chromatic 4.6-dev5-test

本版为带 ESP32、GW5A-25 和机内 microSD 卡槽的 Chromatic 增加 MBC5 实体卡带即时存档。MCU 应用版本为 0.13.8-dev5-test，系统菜单显示 4.6-dev5-test。按机主要求，本轮只做代码、仿真和本地构建，没有刷入掌机。

## 本版变化

- MBC5 类型 19、1A、1B，ROM 最大 8 MiB，支持无 RAM、8 KiB 和 32 KiB RAM 的对应卡头组合。
- 保存和恢复实体卡带 RAM、ROM/RAM 分页以及 RAM 开关；恢复卡槽读写相位后再让 CPU 继续。
- 识别完整 ROM，文件仍保留 A/B 两代和 CRC 校验；卡带识别最长约 8 秒。
- 使用带卡槽状态的新格式 CSS2；旧版 CSS1 文件不能直接读档，先备份原 SNAP 目录，在新版重新保存。
- 修复物理卡带读写信号毛刺，补充中途失败后的总线恢复和游戏重启处理。
- 保留 dev4 已由机主验证的蓝牙游戏音频及滚轮音量修复，沿用中文菜单和按键待机。

这次新增范围是 MBC5，MBC1/MBC3、RTC、震动和其他特殊卡带尚不支持。三款现有游戏能否使用，需要读取实际卡头并逐盘真机测试。原理、参考资料和仿真范围见[即时存档研究与实现](即时存档研究与实现.md)。

## 本轮验证

2026-11-17，配套 MCU 编译通过，完整回归记录包含 33 条 PASS。测试覆盖 8 KiB / 32 KiB 实体 RAM 模型、完整 8 MiB ROM 的 512 个分页、普通/双倍速 CPU 跨相位恢复、HALT/STOP/中断/DMA、文件中断与损坏处理，以及既有待机和蓝牙回归。

GW5A-25 版本 A 完成最终布线，分析 57,430 条路径，建立/保持违例均为 0。最差建立余量 +0.181 ns，保持余量 +0.119 ns，恢复/移除余量为 +0.979 / +0.058 ns。使用原有时钟频率和约束，布局选项为 2。[回归记录](../verification/tests-dev5.log) · [时序摘要](../verification/timing-dev5.txt)

## 稍后真机测试

准备有空余空间的 FAT32 microSD、实体卡带和 USB 数据线。卡内可以保留其他文件，不必使用空卡。游戏由实体卡带运行。

先用原配《俄罗斯方块》做第一轮：进入游戏制造容易辨认的画面，打开「主页 → 即时存档」，按 A 保存，等显示 Saved 后继续游戏改变画面。先测试同次开机读档：按 B 选择读档，再按 B 确认，预期回到保存点；通过后再测试关机重启后的读档。

每盘游戏分别检查画面、声音、按键、分页和游戏自带存档。读档会一起回退卡带 RAM，重要进度先备份。先完成单机测试，联机状态不在本轮支持范围。

## 安装与恢复

本版需要配套的 MCU 和 FPGA。已使用 dev4 相同分区布局的测试机只需更新应用镜像及 FPGA 位流；首次安装请按[安装与使用](安装与使用.md)核对硬件、分区和恢复文件。具体刷写在接好设备后进行。

旧的 dev4 蓝牙验证包继续保留，可用于回退。本版是非官方开发测试固件，尚无本轮商业卡带真机验收；刷写或读档测试可能造成无法开机或进度丢失，请保留备份和恢复文件。
