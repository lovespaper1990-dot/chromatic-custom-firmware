# ModRetro Chromatic 4.6-dev3 真机测试版

本版针对 4.6-dev2 真机上的三项反馈修改了中文菜单、蓝牙音量和耳机重连。适用于配有 ESP32、使用 GW5A-25 FPGA 的 Chromatic。蓝牙和菜单不需要 microSD。

## 2026-11-12 真机进度

掌机刷入后回报整机版本 `4.6-dev3`、MCU `0.13.8-dev3` 和 FPGA `18.14`。FPGA 读回的 928574 字节与刷机包一致。本地保留的 `Chromatic-4.6-dev3.zip` 的 SHA256 为 `d146445a66b1a24c0e4d07f11e357dc64ceb43869c7bbe119cef39bbc9e1698b`。

机主实测蓝牙耳机能连接，但听不到游戏声音。滚轮调音量的听感和断电后的耳机回连仍待实测。下次从这台机器的 dev3 继续，先确认耳机连接后是否进入音频播放状态，再检查送往耳机的游戏音频和滚轮音量值。

## 在掌机上试用

1. 在「系统 → 语言」切换到中文。分别查看主页的「亮度」、显示页的「帧混合」、色温页和系统页的「固件」。检查选中的字与框线中间是否有空隙，「开」和「1:1」是否各自在开关的一边。
2. 在主页的「蓝牙」连接耳机，回到有音乐的游戏。把滚轮从低调到高，再调回最低。留意左右耳是否一起变化，最低位置是否静音。耳机自身音量也会影响最终响度。
3. 连接成功后，把掌机关机再开机，耳机保持开机并处于可连接状态。掌机会主动尝试连接上次的耳机。如果耳机开得晚，进入蓝牙页选上次的耳机，按 A 重连。要更换耳机，用 B 切到搜索。菜单中主动关闭蓝牙后，下次开机不会自动连接；已保存的耳机仍可手动重连。

从 dev2 升级时，如果蓝牙系统只留有一副已配对的耳机，固件会尝试沿用这条记录。如果没有记录，或有多副耳机而无法确定上次使用哪一副，首次需要手动选择并连接一次。

## 从 4.6-dev2 升级

本包包含相互配套的 MCU 和 FPGA。先保留上一个版本和已有备份。解压后可在包根目录运行 `shasum -a 256 -c SHA256SUMS` 核对所有文件。掌机保持开机，用 USB 数据线连接 Mac，直到两次写入和校验都完成。

1. ESP32 使用 esptool 4.x。已经安装本项目 4.6-dev2 的设备可以仅更新应用：在包根目录执行 `python -m esptool --chip esp32 --port PORT --baud 115200 --after hard_reset write_flash 0x10000 esp32/mcu_fw.bin`，将 `PORT` 替换成这台掌机的串口。如果从原厂系统首次安装，进入包内的 `esp32` 目录，使用 `python -m esptool --chip esp32 --port PORT --baud 115200 --after hard_reset write_flash @flash_args` 写入本项目所需的引导程序、分区表和应用。以上命令均保留 NVS 设置。
2. 在包根目录执行 `openFPGALoader --cable gwu2x --detect` 核对 GW5A-25，然后执行 `openFPGALoader --cable gwu2x --write-flash --verify --reset fpga/evt1_x2.fs`。完成后进入「系统 → 固件」，整机应显示 `4.6-dev3`，MCU 应显示 `0.13.8-dev3`。FPGA 沿用上游版本号 `18.14 (dbg)`，请以写入校验确认使用本包的 FPGA。
3. 要退回 4.6-dev2，使用上一版配套的 MCU 和 FPGA 镜像，按相同顺序写入并核对版本。

本版保留了按键待机和原有即时存档范围。待机时保持开关在 ON，游戏画面长按 MENU 约 1.5 秒，熄屏后松手；再次短按并松手可唤醒。关机或拔卡会丢失待机现场。microSD 即时存档支持 32 KiB ROM-only、无卡带 RAM 的实体卡带。

本固件是非官方开发测试版。编译、主机测试和 FPGA 时序检查无法代替真机对屏幕观感、耳机音量和冷启动回连的验证。测试前请备份重要存档。源码、许可证与上一版可在 [项目仓库](https://github.com/lovespaper1990-dot/chromatic-custom-firmware) 查阅；本包内的字体授权见 `licenses/OSD-CJK-LICENSE.txt`。
