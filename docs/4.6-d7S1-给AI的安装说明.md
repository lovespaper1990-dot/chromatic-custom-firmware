# 给 AI 或命令行使用者的 d7S1 安装说明

此包用于已获机主同意刷写、具有 ESP32、microSD 与 GW5A-25 的 Chromatic EVT1 X2。刷写前核对型号，备份 `SNAP`、`SNAPV` 和原生游戏存档。向机主说明刷机及断电可能造成存档损坏或启动异常。请先检查包内的 `开始这里.md`。

1. 下载并完整解压 `Chromatic-4.6-d7S1-install.zip`。保持包中 `fpga`、`esp32`、`tools` 等相对路径。
2. 从根目录运行对应一键入口。依赖已安装时可先运行 `python3 tools/flash_firmware.py --check` 做离线校验。运行 `python3 tools/flash_firmware.py --dry-run` 查看操作顺序。
3. 让机主确认配套镜像和待刷设备，按安装器交互提示完成刷写和校验。请保持设备连接和供电。
4. 重启后到系统固件页核对 `v4.6-d7S1`。串口 `fwversion` 应报告 MCU `v0.13.8-dev7-SD-snap1`。如校验或预检失败，保留报错，按安装器提示处理，切勿盲写。
5. 核对普通档和实体卡旧档时，使用读取或文件清单，避免对现有槽做写入试验。分享诊断前检查公开内容，去掉本机路径和设备识别信息。
